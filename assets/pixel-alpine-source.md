# Pixel alpine background and display typeface

- `pixel-alpine-world.png`: original AI-generated pixel landscape created for this homepage on 2026-09-15. Alpine mountains, pine forest, lake and twilight sky; no extracted game assets.
- `fonts/Silkscreen-Regular.ttf`: Silkscreen by Jason Kottke, distributed by Google Fonts under the SIL Open Font License 1.1. Full license is included in `fonts/OFL.txt`.
- Font source: https://github.com/google/fonts/tree/main/ofl/silkscreen
- Pixel display typography is limited to the site title, section headings and navigation. Academic prose, paper titles, metadata, logos and the profile photograph retain conventional rendering for legibility.
